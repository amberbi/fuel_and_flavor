# Fuel & Flavor

Fuel & Flavor is a responsive culinary website developed as a Web Programming course project. The site is designed to help users discover quick, healthy, and affordable meals through an organized, user-friendly interface.

## Features

- Responsive design for desktop, tablet, and mobile devices
- Dynamic recipe content generated using PHP arrays
- Shared navigation, header, and footer using PHP `include()`
- Meal comparison guide for informed recipe selection
- Recipe submission form with server-side validation
- CSS-only interactive recipe cards
- Clean, semantic HTML and reusable CSS structure

## Technologies Used

- PHP
- HTML5
- CSS3
- Git & GitHub

## Getting Started

1. Clone the repository.
2. Open the project in your preferred code editor.
3. Run the project using a local PHP server (such as XAMPP, MAMP, or PHP's built-in server).
4. Open the project in your web browser.
